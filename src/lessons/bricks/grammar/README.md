# Grammar Brick

Live preview: http://localhost:5173/bricks/grammar

Run `npm run dev:vite` first.

## Model-authored shape

```json
{
  "title": "Grammar point title",
  "explanation": "Plain-English explanation",
  "examples": ["Short Esperanto example"]
}
```

Teach one compact grammar or usage point. Use one short English explanation and
one to three short Esperanto examples.
