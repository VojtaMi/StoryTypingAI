# Story Brick

Live preview: http://localhost:5173/bricks/story

Run `npm run dev:vite` first.

## Model-authored shape

```json
{
  "sentences": [
    "Short Esperanto sentence using introduced words",
    "Another short Esperanto sentence"
  ]
}
```

Write one to five short Esperanto practice sentences. Use mostly introduced
words and very basic known words; do not include English.
