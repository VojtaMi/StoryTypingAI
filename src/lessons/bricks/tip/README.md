# Tip Brick

Live preview: http://localhost:5173/bricks/tip

Run `npm run dev:vite` first.

## Model-authored shape

```json
{
  "title": "Short tip title",
  "body": ["One short learner-facing tip paragraph"]
}
```

Use one or two concise English paragraphs. The tip should clarify pronunciation,
grammar, usage, memory, or learning strategy for this lesson.
