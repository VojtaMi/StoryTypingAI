## Curriculum roadmap

This roadmap tracks the order in which Esperanto concepts should be introduced.

The curriculum should introduce grammar in small usable steps:

1. sentence pattern
2. example story
3. controlled practice
4. reuse in later lessons
5. delayed formal explanation when needed

---

# Stage 1 · Basic noun/adjective sentences

## Already introduced

* Special Esperanto characters: ĉ, ĝ, ĥ, ĵ, ŝ, ŭ
* Basic copula sentence with `estas`

  * *Hundo estas besto.*
  * *Mi estas homo.*
* Nouns ending in `-o`

  * *hundo, besto, homo, kato, nomo*
* Adjectives ending in `-a`

  * *bruna, blua, blanka*
* Basic adjective + noun phrases

  * *bruna hundo*
  * *blua aŭto*
* Possessives

  * *mia, via, nia*
* Article `la`

  * *la homo*
  * *la kato*
* Pronouns introduced

  * *mi, vi, li, ŝi*

## Important note

Adjectives have only been used in their simple singular form so far.

Later, adjectives must agree with nouns in:

* plural: *bela hundo* → *belaj hundoj*
* accusative: *bela hundo* → *belan hundon*
* plural accusative: *belaj hundoj* → *belajn hundojn*

Do not teach full agreement too early, but avoid saying that adjectives never change.

# Stage 2 · First real actions

Goal: move beyond `estas` into normal present-tense verbs.

## Concepts to introduce

| Concept                            | Example                 |
| ---------------------------------- | ----------------------- |
| Present tense `-as`                | *Mi havas hundon.*      |
| Infinitive `-i` as dictionary form | *havi* → *havas*        |
| Direct object `-n`                 | *Mi vidas katon.*       |
| Basic word order                   | subject → verb → object |
| Negation with `ne`                 | *Mi ne havas katon.*    |

## High-priority vocabulary

| Esperanto | English  | Type |
| --------- | -------- | ---- |
| havi      | to have  | verb |
| vidi      | to see   | verb |
| ŝati      | to like  | verb |
| voli      | to want  | verb |
| manĝi     | to eat   | verb |
| trinki    | to drink | verb |
| libro     | book     | noun |
| pomo      | apple    | noun |
| akvo      | water    | noun |
| pano      | bread    | noun |

## Suggested lessons

### 5 · Mi havas hundon

**New vocabulary**

| Esperanto | English |
| --------- | ------- |
| havi      | to have |
| libro     | book    |
| pomo      | apple   |

**Grammar**

* present tense `-as`
* infinitive/dictionary form `-i`
* direct object `-n`

**Story**

```eo
Mi havas hundon.
Vi havas libron.
La hundo havas pomon.
```

---

### 6 · Mi ne havas katon

**New vocabulary**

| Esperanto | English |
| --------- | ------- |
| ne        | not     |
| vidi      | to see  |
| ŝati      | to like |

**Grammar**

* negation with `ne`
* reuse of accusative `-n`

**Story**

```eo
Mi vidas hundon.
Mi ne vidas katon.
Vi ŝatas la hundon.
La kato ne ŝatas la hundon.
```

# Stage 3 · Plural and adjective agreement

Goal: teach that Esperanto marks plural consistently.

## Concepts

| Concept                    | Example                     |
| -------------------------- | --------------------------- |
| Plural noun `-j`           | *hundoj*                    |
| Plural adjective `-aj`     | *brunaj hundoj*             |
| Plural object `-jn`        | *Mi vidas hundojn.*         |
| Adjective + noun agreement | *Mi vidas brunajn hundojn.* |

## Vocabulary

| Esperanto | English   |
| --------- | --------- |
| birdo     | bird      |
| arbo      | tree      |
| floro     | flower    |
| domo      | house     |
| granda    | big       |
| malgranda | small     |
| bela      | beautiful |
| bona      | good      |

## Suggested lesson

### 7 · Grandaj hundoj

**Grammar**

* plural `-j`
* adjective agreement
* plural accusative `-jn`

**Story**

```eo
La hundo estas granda.
La hundoj estas grandaj.
Mi vidas grandan hundon.
Mi vidas grandajn hundojn.
```

# Stage 16 · `-ig-` and `-iĝ-`

Goal: introduce one of the most important Esperanto distinctions.

## Concepts

| Affix  | Meaning      | Example                 |
| ------ | ------------ | ----------------------- |
| `-ig-` | make / cause | *varmigi* = make warm   |
| `-iĝ-` | become       | *varmiĝi* = become warm |

## Examples

```eo
La akvo estas varma.
Mi varmigas la akvon.
La akvo varmiĝas.

La pordo estas malfermita.
Mi malfermas la pordon.
La pordo malfermiĝas.
```

# Stage 17 · Correlatives

Goal: introduce the full table only after the learner already knows basic question words.

## Introduce row by row

| Series  | Meaning             |
| ------- | ------------------- |

| `i-`    | some                |

| ------ | ------------------ |
| `-o`   | thing              |
| `-u`   | individual / which |
| `-a`   | kind               |
| `-e`   | place              |
| `-am`  | time               |
| `-el`  | manner             |
| `-al`  | reason             |
| `-om`  | amount             |
| `-es`  | possession         |

## Examples


# Stage 18 · Relative clauses

Goal: connect ideas naturally.

## Concepts

| Concept           | Example                      |
| ----------------- | ---------------------------- |
| relative `kiu`    | *La homo, kiu parolas...*    |
| accusative `kiun` | *La homon, kiun mi vidas...* |
| relative `kio`    | *Tio, kion vi diras...*      |
| relative `kie`    | *La domo, kie mi loĝas...*   |

## Examples

```eo
La homo, kiu parolas, estas mia amiko.
La libron, kiun mi legas, mi ŝatas.
Mi ne komprenas tion, kion vi diras.
Jen la domo, kie mi loĝas.
```

# Stage 19 · Participles

Goal: introduce advanced verb-derived adjectives and nouns.

## Active participles

| Ending  | Meaning     |
| ------- | ----------- |
| `-ant-` | doing       |
| `-int-` | having done |
| `-ont-` | about to do |

Examples:

```eo

legonta homo
```

## Passive participles

| Ending | Meaning          |
| ------ | ---------------- |
| `-at-` | being done       |
| `-it-` | having been done |
| `-ot-` | about to be done |

Examples:

```eo
legata libro
legita libro
legota libro
```

# Stage 20 · Advanced style

Goal: move from correct Esperanto to natural Esperanto.

## Concepts

* flexible word order and emphasis
* `ja`, `nu`, `do`, `jen`, `ajn`
* `por` vs `pro`
* `per` vs `kun`
* `de` vs `da`
* formal vs casual style
* avoiding overbuilt words
* writing clearly for international readers

## Examples

```eo
Mi faras tion por vi.
Mi faras tion pro vi.

Glaso da akvo.
Grupo de homoj.

Kiu ajn povas veni.
Nu, mi ne certas.
Tio ja gravas.
```
